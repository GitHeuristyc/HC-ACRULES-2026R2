# HC-ACRULES-2026R2

ast-grep rules that CodeRabbit runs on Heuristyc pull requests whose destination is Acumatica 2026R2.

Heuristyc generates this repository from its internal skills (branch `2026r2`). Do not edit it here: changes are overwritten on the next publish.

| Folder | Contents |
|---|---|
| `rules/` | One ast-grep rule per file. `metadata.skill` names the skill the rule comes from. |
| `rule-tests/` | Valid and invalid examples for each rule, run with `ast-grep test`. |
| `utils/` | Shared utility rules. |

CodeRabbit loads this repository as an ast-grep package (`reviews.tools.ast-grep.packages`), which must be public.
